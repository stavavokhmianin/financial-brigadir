# REPORT 6.2 — Режим пилота и on-prem-профиль

- **Этап:** 6 (спринт 3)
- **Роль по 16.1:** A + C
- **Коммит:** [`7794605`](https://github.com/stavavokhmianin/financial-brigadir/commit/7794605) в `step4ik`

## Режим пилота (A)

- Одна переменная `APP_MODE=pilot`.
  - Выключаются демо-профили, учебный банк и Swagger UI (он грузит скрипты с CDN).
  - Они отвечают 404 `not_available`.
  - `GET /api/v1/meta` сообщает клиенту режим и версию условий пилота.
- **Вход участника** — `POST /api/v1/pilot/sessions`: персональный код и принятая версия условий.
  - Код: 16 символов без похожих букв (80 бит). В БД хранится только SHA-256, как у токенов.
  - Первый вход создаёт пустой профиль. Повторный вход по тому же коду открывает тот же
    профиль, если код не истёк и не отозван.
  - Сессия живёт не дольше кода. Версия условий записывается в профиль и в журнал аудита.
- **CLI оператора** `python -m app.cli`:
  - `invite` — выдать коды;
  - `list-codes` — список без секретов;
  - `revoke-code` — отозвать код;
  - `reapply-erasures` — повторить удаления.
- **Удаление и бэкапы (раздел 25).** При удалении профиля его случайный id пишется в таблицу
  `erasure_log` и в файл на отдельном томе. После восстановления старого бэкапа
  `restore.sh` удаляет такие профили снова. Данных профиля в журнале нет.
- **Миграция 0007:** таблицы `pilot_access_codes` и `erasure_log`.

## On-prem-контур (C), `infra/pilot`

- **nginx — единственная точка входа:**
  - TLS 1.2/1.3, HSTS, CSP `script-src 'self'`, `frame-ancestors 'none'`;
  - отдаёт статику web-клиента и проксирует `/api`.
- **Общий limiter:** 10 запросов/с с адреса. Подбор кода — не больше 6 попыток в минуту.
- **Изоляция:** API, воркер и PostgreSQL — во внутренней сети `internal: true`, без выхода в
  интернет. Наружу опубликован только порт прокси.
- **Секреты** — файлами docker secrets: пароль БД, строка подключения, ключ бэкапов.
  В git и в образы они не попадают (`.gitignore`, `.dockerignore`).
- **Бэкап** `pg_dump` шифруется AES-256 + PBKDF2. `restore.sh` расшифровывает дамп,
  загружает его и повторяет удаления.
- **Runbook оператора** — `docs/pilot.md`. Там же список того, что подтверждает площадка:
  шифрование дисков, сертификат УЦ, срок хранения бэкапов, 152-ФЗ.

## Клиент (B)

- Стартовый экран спрашивает режим у стенда.
  - В пилоте показывает условия, флажок согласия и поле кода. Регистр и дефисы не важны.
  - Учебный банк вне демо скрыт.
- В пустом профиле нет прогноза «из нуля рублей с высоким риском». Вместо него — приглашение
  добавить счёт. Первый вход сразу открывает экран добавления, «назад» ведёт на главную.

  после «восстановления», CLI без утечки кодов.
