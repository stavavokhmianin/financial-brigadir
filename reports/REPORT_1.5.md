## Что сделано

### Экран запуска демо (`/`, FR-01, US-01)

- Профили загружаются из `GET /demo/profiles`; профиль «Семья» показан с меткой «после MVP»
  и не выбирается.
- Выбор профиля сделан радиогруппой с a11y-ролями. Кнопка «Запустить демо» вызывает
  `POST /demo/sessions` (seed 42) и переходит на главный экран.
- Есть все состояния по DoD 16.3: загрузка, ошибка с подсказкой
  `docker compose up --build` и кнопкой «Повторить», пустой список, ошибка создания сессии.
- Дисклеймер: сервис не банк, прогноз — модельная оценка, а не гарантированный остаток.

### Главный экран (`/dashboard`, раздел 11.1 — в объёме этапа 1)

- Свободные средства: `liquid_balance_minor` без кредитных лимитов, вкладов и блокировок.
- Дата актуальности данных в часовом поясе пользователя, метки «Демо» и охвата
  (полный / частичный / неизвестен).
- Блок «Ограничения данных» из `data_quality.notes` (13.2): один банк, короткая история,
  кредитный лимит, устаревшие данные.
- Обязательства на 30 дней из календаря `GET /obligations` со статусом
  (подтверждено / предполагается / неточная сумма) и итоговой суммой.
- Счета: кредитка показывается как «Долг X / лимит Y», вклад — «не входит в свободные
  средства», у дебетовой видны блокировки.
- Карточка «Прогноз по дням» честно сообщает, что расчёт появится на следующем этапе:
  фальшивых чисел нет.
- Кнопка «Сменить профиль» и редирект на `/` без сессии.

### Общее

- TypeScript-типы API генерируются из `packages/api_contracts/openapi.yaml`
  (`openapi-typescript`, `npm run gen:api`, запускается в `postinstall`). Клиент не может
  разойтись с контрактом без ошибки `tsc`.
- Тонкий типизированный API-клиент с единым `ApiError`: сеть, `{"error": …}` и 422.
- Токен демо-сессии хранится только в памяти, не в localStorage или AsyncStorage.
- Форматирование денег и дат без `Intl` («55 000 ₽», «21 октября», «19 октября, 10:00»),
  поэтому результат одинаковый в Hermes, браузере и Node.
- Светлая и тёмная тема, ширина колонки до 720 px на web, `EXPO_PUBLIC_API_URL`
  (по умолчанию `localhost:8000`, на эмуляторе Android — `10.0.2.2:8000`).

## Как проверить

```bash
docker compose up --build              # API + Postgres + smoke
cd apps/client && npm install && npx expo start --web
```

Демо-сценарий: «Молодой специалист» → «Запустить демо». На главном экране:
- свободные средства **55 000 ₽** на 19 октября, 10:00;
- обязательства: потребкредит **12 000 ₽ — 21 октября**, аренда **30 000 ₽ — 23 октября**.

Это вход для демо 16.4: перед зарплатой 25.10 остаток подходит к резерву.

## Тесты

- `tests/format.test.ts` и `tests/dashboard-logic.test.ts` (node --test): деньги, даты,
  часовой пояс, склонения, окно и сумма обязательств, отображение кредитки, вклада и
  дебетовой карты.
- `tsc --noEmit` в strict-режиме с `noUncheckedIndexedAccess` на сгенерированных из
  контракта типах.
- `expo export --platform web` — сборка web-бандла в CI.

CI: прогон коммита `ee1f324` на момент публикации стоял в очереди GitHub Actions. Итог
(`tsc`, node-тесты, web-сборка, compose-smoke с новым демо-сценарием) смотрите во вкладке Actions.
Предыдущие прогоны (1.1, 1.2) зелёные по всем трём задачам.
