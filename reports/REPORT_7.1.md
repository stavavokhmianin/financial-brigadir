# REPORT 7.1 — APK на настоящем телефоне и стабильный Android E2E

- **Этап:** 7 (после финала, 16.2: «первые пользователи»)
- **Роль по 16.1:** B
- **Коммиты:** [`99a66d5`](https://github.com/stavavokhmianin/financial-brigadir/commit/99a66d5),
  [`a48557a`](https://github.com/stavavokhmianin/financial-brigadir/commit/a48557a) в `step4ik`

## Что случилось

Участник команды поставил APK из CI на свой Android и увидел «Не удалось загрузить профили.
Сервер недоступен». Ошибки в приложении нет: APK собран для проверки на эмуляторе, и адрес
API в нём `http://127.0.0.1:8000`. На эмуляторе `adb reverse` переводит этот адрес на
компьютер, а на настоящем телефоне это сам телефон, где сервера нет. Перенастроить адрес
без пересборки было нельзя.

## Что сделано

- **Адрес сервера на стартовом экране.** Если API недоступен, вместо тупика появляется
  карточка «Адрес сервера».
  - Можно ввести адрес ноутбука в той же Wi-Fi или стенда команды: `192.168.1.5:8000`
    превращается в `http://192.168.1.5:8000`.
  - Если указан адрес самого телефона, карточка прямо об этом говорит и подсказывает, как
    узнать адрес ноутбука.
  - Адрес действует до перезапуска приложения.
  - Preview-сборка разрешает http в локальной сети, production — только https (это уже
    было в `app.config.js`).
- **`docs/mobile-verification.md`** — пошаговая проверка APK по Wi-Fi без кабеля.
- **Последняя кнопка под панелью навигации.** Android E2E на 6.4 упал: касание
  «Учебный банк (мок)» попало в системную панель. Разбор кадров показал настоящий баг
  интерфейса. В SDK 54 приложение рисуется edge-to-edge, и последняя кнопка главного экрана
  («Приватность, экспорт и выход») уходила под панель навигации — так было бы и у людей.
  Теперь `Screen` добавляет нижний отступ safe area.
- **Сценарий Maestro.** Первая попытка (`centerElement`) не годится для кнопок в конце
  страницы: дальше прокрутка не идёт, и тест упал уже на «Free и Plus». Теперь сценарий
  прокручивает главный экран до конца и только потом нажимает нижние кнопки.

## Как проверить на своём телефоне

1. На ноутбуке: `docker compose up --build`.
2. Узнать адрес ноутбука: `ipconfig` на Windows или `ip addr` на Linux/macOS.
3. В приложении ввести адрес вида `192.168.1.5:8000` и нажать «Подключиться».
   Телефон и ноутбук должны быть в одной сети, брандмауэр должен пропускать порт 8000.

- **В браузере:** сборка с заведомо неверным адресом показывает карточку; после ввода
  адреса живого API открывается выбор демо-профилей.

  - [видео демо](https://github.com/stavavokhmianin/financial-brigadir/actions/runs/39680409299).
