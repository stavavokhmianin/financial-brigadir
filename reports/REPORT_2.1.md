## Что сделано

### API — `POST /api/v1/imports/csv`

- Два режима: `preview` (только разбор, без записи) и `import`.
- Принимает `file` (multipart) или `content` (текст в поле формы): мобильному клиенту не
  нужен нативный выбор файла.
- Идемпотентность:
  - тот же файл (SHA-256) или тот же `Idempotency-Key` → прежний результат с
    `already_imported: true`, код 200;
  - тот же ключ с другим файлом → `409 idempotency_conflict`;
  - при пересекающихся выписках уже известные строки не дублируются (`rows_duplicate`).
- Ошибки:
  - файл непригоден целиком → `400` с кодом (`empty_file`, `missing_columns`, `bad_encoding`,
    `no_valid_rows`);
  - файл больше 2 МБ → `413`;
  - чужой счёт → `404`.
- Импорт записывается в `import_batches`, у операций есть `import_batch_id`, у источника
  обновляются `data_as_of` и период истории (FR-04).

### `CsvImportAdapter` (раздел 7.1–7.2)

- Кодировки UTF-8, UTF-8 с BOM, Windows-1251. Разделитель `;`, `,` или табуляция
  определяется автоматически.
- Заголовки распознаются по синонимам на русском и английском (`Дата операции`, `Сумма`,
  `Назначение платежа`, `amount`…). Сопоставление колонок возвращается в ответе.
- Даты `ГГГГ-ММ-ДД`, `ДД.ММ.ГГГГ`, `ДД.ММ.ГГ`, ISO со смещением, со временем и без.
  Дата без времени считается полуднем в часовом поясе пользователя и хранится в UTC.
- Суммы: `-1 450,00`, `1450.5`, неразрывные пробелы. Колонка «Тип операции»
  (Списание/Зачисление) задаёт знак, если суммы без знака.
- **Ничего не исправляется молча (7.2):** строка с плохой датой, суммой, нулём, валютой
  ≠ RUB или непонятным статусом отклоняется, в `issues` попадают номер строки, колонка и причина.
- Экономический тип (FR-09): «перевод между своими» → `transfer_*`, «погашение кредитной
  карты» → `credit_payment`, «возврат» → `refund`, иначе по знаку. Статусы: исполнено /
  в обработке / отменено.
- Категоризация по правилам (FR-10): продукты, кафе, такси, транспорт, аптека, маркетплейсы,
  ЖКХ, аренда, зарплата. Источник категории сохраняется (`source` или `rule`), поэтому
  ручное исправление отличимо.
- Стабильный `external_id` для строк без номера: хэш даты, суммы, описания и порядкового
  номера одинаковых строк в файле.
- Безопасность (раздел 25): лимит 2 МБ и 20 000 строк, экранирование текста, начинающегося
  с `= + - @`, файл на диск не сохраняется.

### Клиент — экран «Импорт выписки» (`/import`)

- Выбор счёта, вставка текста CSV, кнопка «Вставить пример».
- «Проверить» показывает предпросмотр: найденные колонки, период, первые строки с суммами
  и типами, ошибки по строкам.
- «Импортировать» доступно только после предпросмотра того же текста; итог — сколько
  добавлено, сколько уже было, сколько отклонено.
- Кнопка «Загрузить выписку CSV» на главном экране.

## Ограничения и следующий шаг

- Остаток счёта после импорта не пересчитывается из выписки. Остаток задаёт пользователь
  или источник (FR-03), выписка добавляет историю для модели трат. Расхождение ручного и
  импортированного остатка будет показываться в метке качества (аномалия из 12.3).
- Вероятные дубли с разными датами учёта (FR-08) выявляются на этапе 4 вместе с
  дедупликацией.
