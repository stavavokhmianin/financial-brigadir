# REPORT 5.3 — Качество данных и критерии приёмки

Дата: 21.10.2026. Основание: 13.2–13.4, 19, 26.1 ТЗ.
Код: [`c7201df`](https://github.com/stavavokhmianin/financial-brigadir/commit/c7201df), `step4ik`.

## Изменения

- CSV-источники теперь участвуют в качестве данных, даже когда исходный источник
  счёта — синтетика или ручной ввод. Смешение CSV и демо явно обозначается;
  свежесть проверяется по текущему времени, прогноз не замораживается на дате демо.
- Частично отклонённый CSV получает флаг неполноты. Следующий файл сам по себе
  не снимает этот флаг: он не доказывает восстановление всех пропусков.
- Ручные остатки учитываются в свежести; длина истории не бывает отрицательной,
  при нескольких источниках используется консервативный общий период.
- Убрано обещание «без риска» в расчётном лимите покупки.
- Исправлен контраст статуса экспорта в тёмной теме; при выходе закрывается история экранов.
- `docs/quality-gates.md`: сопоставление всех 14 критериев §19 с проверками,
  условия приёмки и список оставшихся ручных/инфраструктурных проверок.

## Проверки

- После изменений качества: **246 passed, 1 skipped**; Ruff, mypy strict и TypeScript чистые.
- 23 клиентских теста, локальные web/Android/iOS экспорты — успешно.
- В браузере вручную пройден сценарий: демо → прогноз → учебный банк → согласие →

  заблокированная синхронизация → экспорт JSON → выход.
- Сценарии удаления и изоляции проверены API-тестами. Браузерное удаление и физическое
  мобильное устройство не заявляются проверенными.
