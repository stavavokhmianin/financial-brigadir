# История версий Financial SDK

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## 0.1.0 — 2026-11-01

- Публичный фасад `FinancialEngine` для `baseline-0.2` и `mc-0.3`.
- Прогноз, безопасная сумма и контрфактическое сценарное моделирование.
- Универсальный вход `FinancialData` и JSON-нормализация.
- Синхронные и асинхронные адаптеры, CSV и Open Banking контракты.
- JSON-сериализация без FastAPI, Pydantic и ORM.
