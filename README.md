# Финансовый бригадир

Прогноз личных денежных потоков и вероятности кассового разрыва: сколько можно
потратить сегодня, учитывая платежи, доходы и неопределённость ближайших недель.
Основа — единое ТЗ v2.0 от 19.10.2026.

## Как устроен репозиторий

| Ветка     | Что лежит                                                                 |
|-----------|---------------------------------------------------------------------------|
| `master`  | Только отчёты о сделанном: [`reports/`](reports/README.md)                |
| `step4ik` | Код: monorepo (Expo-клиент, FastAPI-сервис, `forecast_core`, генератор, инфраструктура) |

Отчёты именуются `reports/REPORT_<этап>.<задача>.md`, где этап — строка плана
из раздела 16.2 ТЗ («19–22 октября» = этап 1), задача — пункт обязательного
результата этого этапа. Индекс — в [`reports/README.md`](reports/README.md).

Инструкция по запуску — в `README.md` ветки `step4ik`.
