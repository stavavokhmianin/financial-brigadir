# План проверки алгоритмов и продукта (черновик)

Основание: раздел 15 ТЗ. Цифры заполняются только по факту измерений.

## Baselines (15.2)

- **A — календарь.** Только подтверждённые обязательства и доходы по датам.
- **B — календарь + медиана.** К A добавляется медианный дневной расход по дням недели.
- **Модель.** Вероятностная симуляция (этап 2–15 ноября) сравнивается с A и B на одних и
  тех же периодах и при одинаковой полноте данных.

## Протокол

- Разбиение по времени: обучение на ранних периодах, валидация на поздних, без перемешивания.
- Генератор (`packages/synthetic_generator`) отделяет `known` (то, что известно на `as_of`)
  от `hidden_future` (что случится на самом деле). В признаки попадает только `known`.
- Метрики: recall и precision событий нехватки на горизонтах 3/7/14/30 дней, MAE остатка
  по дням, Brier score, калибровка по корзинам, доля ложных тревог.
