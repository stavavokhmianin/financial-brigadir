# Импорт CSV-выписки (FR-02)

Эндпоинт: `POST /api/v1/imports/csv` (multipart). Пример файла:
`packages/api_contracts/examples/statement-template.csv`.

## Поля запроса

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `account_id` | да | счёт пользователя, к которому относится выписка |
| `mode` | нет | `preview` (по умолчанию) — только разбор, `import` — запись |
| `file` | одно из двух | CSV-файл до 2 МБ |
| `content` | одно из двух | текст CSV (удобно для мобильного клиента без выбора файла) |
| `Idempotency-Key` | нет | заголовок; повтор с тем же ключом вернёт тот же результат |

## Формат файла

- Кодировка UTF-8 (с BOM или без) или Windows-1251.
- Разделитель `;`, `,` или табуляция (определяется автоматически).
- Обязательные колонки: дата и сумма. Остальные — по желанию.

| Поле | Распознаваемые заголовки |
|------|--------------------------|
| дата | Дата, Дата операции, date, … |
| сумма | Сумма, Сумма операции, amount, … (`-1 450,00`, `1450.5`) |
| дата проводки | Дата списания, Дата проводки, booked_at |
| описание | Описание, Назначение платежа, description |
| категория | Категория, category (иначе — по правилам) |
| статус | Статус: исполнено / в обработке / отменено |
| валюта | Валюта: только RUB в MVP |
| направление | Тип операции: Списание / Зачисление (если суммы без знака) |
| id | Номер операции, id (иначе — стабильный хэш строки) |

Дата без времени считается полуднем по часовому поясу пользователя. Время хранится в UTC.

## Правила

- **Ничего не исправляется молча.** Строка с непонятной датой, суммой, валютой или статусом
  отклоняется, а в `issues` попадают номер строки, колонка и причина.
- **Идемпотентность.** Тот же файл (SHA-256) или тот же `Idempotency-Key` возвращает прежний
  результат с `already_imported: true`. Строки, уже известные по `external_id`, при
  пересекающихся выписках не дублируются (`rows_duplicate`).
- **Экономический тип** определяется по знаку и описанию: «перевод между своими» →
  `transfer_*`, «погашение кредитной карты» → `credit_payment`, «возврат» → `refund`.
  Такие операции не попадают в модель повседневных трат.
- **Безопасность.** Лимит 2 МБ и 20 000 строк. Текст, начинающийся с `= + - @`, экранируется
  апострофом, чтобы не стать формулой при выгрузке в таблицу. Файлы на диск не сохраняются.
